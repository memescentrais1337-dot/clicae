# Pasta de Vídeos (CLICAÊ)

Esta pasta armazena os arquivos de vídeo demonstrativos dos projetos, reels das bios criadas e vídeos de apresentação.

### Como usar:
- Qualquer vídeo colocado aqui pode ser acessado diretamente na URL com o caminho `/video/nome-do-arquivo.extensao`.
- Exemplo: `/video/onze_lounge_reel.mp4`, `/video/dj_hirla_show.mp4`.
- Formatos recomendados: `.mp4` (H.264/AAC para compatibilidade universal com iOS/Android) e `.webm`.

### Boas práticas:
- Atributos recomendados na tag `<video>`:
  `autoPlay`, `muted`, `loop`, `playsInline`, `preload="metadata"`
- Mantenha os vídeos comprimidos (geralmente abaixo de 5MB) para carregamento instantâneo em redes 4G/5G.

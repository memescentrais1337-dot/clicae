# Pasta de Imagens (CLICAÊ)

Esta pasta armazena todas as imagens estáticas, fotos de clientes, logotipos e banners do site.

### Como usar:
- Qualquer imagem colocada aqui pode ser acessada diretamente na URL com o caminho `/imagem/nome-do-arquivo.extensao`.
- Formatos recomendados: `.jpg`, `.png`, `.webp`, `.svg`.

### Imagens atuais disponíveis:
- `/imagem/onze_lounge.jpg` — Foto do ambiente Onze Lounge
- `/imagem/dj_hirla.jpg` — Foto da apresentação DJ Hirla
- `/imagem/hero_atmosphere.jpg` — Textura visual de iluminação neon
- `/imagem/logo.svg` — Logotipo vetorial da Clicaê
